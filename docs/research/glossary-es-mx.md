# Glossary: English → Latin-American Spanish (es-MX)

One place to fix names for *The Legend of Zelda: Ocarina of Time* (Nintendo
Switch 2, 2026). Later passes change a name here first, then search and
replace it in `src/content/games/oot/es/` (and `aliases.json`).

- **Compiled:** 2026-11-08, from `docs/research/remake-2026.md` §6 (and §0, §4)
  plus the Spanish strings of the old 3DS guide (`docs/reference-3ds/es/`),
  which follow Nintendo's Spanish of that era.
- **English column:** the remake's English name. Where the remake renamed
  something, the old 3DS/N64 name is in the notes.
- **Rule for the es pages** (see `oot-common` instructions): use the es-MX name
  when it is official; otherwise the 3DS Spanish name, and on its first mention
  in a page add the English name in parentheses, e.g. «Templo del Bosque
  (Forest Temple)». Remake-only names with no verified Spanish stay in English.

## Confidence key

| Key | Meaning |
|---|---|
| **MX** | Official Latin-American Spanish: Nintendo México's product page for the remake [NIN-MX, 2026-11-08]. Use as is. |
| **LU** | Latin-American press (LevelUp review/news, 2026-11-03/04). Very likely the in-game name. |
| **3DS** | Fallback: the old 3DS guide's Spanish string. Not checked against the remake's LatAm text. Add the English name on first mention when the English name changed. |
| **SERIE** | Usual Spanish name in the series, not found in any repo source. Low confidence. |
| **EN** | No verified Spanish name: keep the English (remake-only names, or names the 3DS guide already kept in English). |
| *ES (Spain)* | Spain's name, listed only so nobody copies it by mistake. Not the guide's target. |
